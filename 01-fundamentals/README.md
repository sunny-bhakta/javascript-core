# JavaScript Fundamentals

This directory contains examples and documentation for fundamental JavaScript concepts.

## Files

- **variables.js** - Variable declarations (`var`, `let`, `const`), scoping, and best practices
- **data-types.js** - Primitive and reference types, type checking, type conversion
- **operators.js** - Arithmetic, logical, comparison, assignment, and other operators

## Key Concepts

### Variables
- Use `const` by default
- Use `let` when reassignment is needed
- Avoid `var` in modern JavaScript
- Understand function scope vs block scope

### Data Types
- **Primitives**: String, Number, Boolean, Undefined, Null, Symbol, BigInt
- **Reference Types**: Object, Array, Function, Date, RegExp
- Understand the difference between primitive and reference types
- Know truthy and falsy values

### Operators
- Arithmetic: `+`, `-`, `*`, `/`, `%`, `**`
- Comparison: `==`, `===`, `!=`, `!==`, `<`, `>`, `<=`, `>=`
- Logical: `&&`, `||`, `!`, `??`
- Assignment: `=`, `+=`, `-=`, `*=`, `/=`, `%=`
- Ternary: `condition ? value1 : value2`
- Optional Chaining: `?.`
- Nullish Coalescing: `??`

## Best Practices

1. Always use `const` unless you need to reassign
2. Use strict equality (`===`) instead of loose equality (`==`)
3. Understand type coercion to avoid unexpected behavior
4. Use template literals for string interpolation
5. Use optional chaining and nullish coalescing for safer code
